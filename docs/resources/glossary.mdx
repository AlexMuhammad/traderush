# Glossary

> Terms used across Trade Rush, DreamDEX Event Contracts, and the docs.

| Term | Meaning |
| --- | --- |
| Event Contract | A binary market that resolves to one of two outcomes |
| Up | The yes/upside outcome leg |
| Down | The no/downside outcome leg |
| Complete set | A matched pair of outcome tokens minted from collateral |
| Duel | Two-player equal-stake challenge |
| Room | Many-player parimutuel pot |
| Run | Direct book-trading path in the console |
| Pot | Total collateral backing a duel or room |
| Parimutuel | Payout model where the winning side splits the whole pot by stake share |
| Collateral | Stablecoin used to mint complete sets and redeem winning outcomes |
| tUSDC | Shannon testnet collateral, 6 decimals |
| USDso | Somnia mainnet collateral, 18 decimals |
| ERC-6909 | Multi-token standard used for outcome balances |
| BinaryMarketsModule | DreamDEX contract used for market records and complete-set minting |
| BinarySettlement | Contract path used to redeem finalized winning outcomes |
| Venue | A DreamDEX market venue namespace |
| Indexer | GraphQL data source used to discover event-contract markets |
| Tick | Minimum valid price increment |
| Lot | Minimum valid size increment |
| IOC | Immediate-or-cancel order behavior |
| Privy | Wallet and login provider used by the frontend |
| Shannon | Somnia testnet |
