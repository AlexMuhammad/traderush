# Hackathon notes

> Verified notes for the Event Contracts Hackathon build.

The DoraHacks page for the Event Contracts Hackathon is protected by human verification when fetched automatically, but public search snippets identify it as the Somnia x DreamDEX Event Contracts Hackathon with a 5,000 USD prize pool. Trade Rush was built against the live Somnia/DreamDEX environment and the local repo's verified findings.

## Live-venue corrections

| Finding | What Trade Rush does |
| --- | --- |
| Event contracts are not listed on `GET /v0/markets` | Uses the indexer and `@somnia-chain/markets-sdk` |
| Testnet collateral has 6 decimals | Formats through network config |
| Settlement is claimed | Keeps claim actions visible |
| Market status is not an on-chain enum | Derives tradability from `tradingStart` and `expiry` |
| Module signatures differed from assumptions | Uses ABI exports from the Somnia markets SDK |
| Reference-mode markets can have strike `0` | Does not parse question text as protocol truth |
