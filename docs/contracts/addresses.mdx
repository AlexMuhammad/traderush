## Escrow environment

| Variable | Purpose |
| --- | --- |
| `DUEL_ESCROW_ADDRESS_TESTNET` | Testnet `DuelEscrow` deploy |
| `DUEL_ESCROW_ADDRESS_MAINNET` | Mainnet `DuelEscrow` deploy |
| `ROOM_ESCROW_ADDRESS_TESTNET` | Testnet `RoomEscrow` deploy |
| `ROOM_ESCROW_ADDRESS_MAINNET` | Mainnet `RoomEscrow` deploy |
| `VITE_DUEL_ESCROW_ADDRESS` | Browser-visible duel escrow |
| `VITE_ROOM_ESCROW_ADDRESS` | Browser-visible room escrow |

<Note>
  A previously verified Shannon duel flow used `DuelEscrow` at `0xbfaaf7b082c5b39dedbb9f9224b6a435bda03a57`. Re-run `pnpm doctor` against your active `.env` before trusting any address.
</Note>
